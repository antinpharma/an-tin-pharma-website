# An Tín Pharma Website

Website catalogue responsive cho An Tín Pharma.

## Chức năng hiện có
- Responsive desktop / tablet / mobile
- Tìm kiếm theo tên sản phẩm, hoạt chất, quy cách
- Lọc danh mục
- Card sản phẩm
- Nút liên hệ Zalo / Facebook
- Sẵn sàng deploy bằng GitHub Pages

## Bước tiếp theo
1. Thay dữ liệu mẫu bằng nguồn dữ liệu thật.
2. Gắn link Zalo và Facebook thật.
3. Thay placeholder bằng ảnh sản phẩm thật.
4. Bật GitHub Pages: Settings → Pages → Deploy from a branch → main / root.

> Lưu ý: dữ liệu mẫu hiện chưa dùng để bán hàng thật. Giá để ở trạng thái “Liên hệ” cho tới khi có nguồn dữ liệu chính thức.
